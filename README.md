# Magician — Demo

A playable demo of a pixel-art magic game in development. You wake up in the
Slime Keep with no memory of how you got there, learn to cast spells by calling
three orbs, find your way up into an old magic tower, brew potions and explore
the forest around it. **The demo ends when you drink the Archmage Potion.**

## Download and play (Windows)

1. Open **[Releases](../../releases/latest)** and download `MagicianDemo-Windows.zip`.
2. Unzip it anywhere (right-click → *Extract All*).
3. Double-click **`MagicianDemo.exe`**. Nothing to install.

If Windows shows *"Windows protected your PC"*, click **More info → Run anyway**
(the game isn't signed, that's all).

## Controls

| Key | What it does |
| --- | --- |
| W A S D | Move |
| 1 · 2 · 3 | Call the Rua, Werz and Xort orbs (three orbs make a spell) |
| Left / right click | Cast the orbs' spell; each button keeps the last spell cast with it |
| Space | Blink (dodge) |
| E | Interact, talk, go on |
| 4 · 5 | Drink a potion |
| K or Esc | The book: inventory, journal, skills, status |

The game saves by itself. Your saves are in `%APPDATA%\MagicianDemo`; to remove
the demo, delete the folder you unzipped and that one.

## Descargar y jugar (Windows)

1. Abre **[Releases](../../releases/latest)** y descarga `MagicianDemo-Windows.zip`.
2. Descomprímelo donde quieras (clic derecho → *Extraer todo*).
3. Haz doble clic en **`MagicianDemo.exe`**. No hay que instalar nada.

Si Windows muestra *"Windows protegió su PC"*, pulsa **Más información → Ejecutar de todas formas**
(el juego no está firmado, nada más).

**La demo termina cuando bebes la Poción de Archimago.**

| Tecla | Qué hace |
| --- | --- |
| W A S D | Moverse |
| 1 · 2 · 3 | Invocar los orbes Rua, Werz y Xort (tres orbes forman un hechizo) |
| Clic izquierdo / derecho | Lanzar el hechizo de los orbes; cada botón guarda el último lanzado con él |
| Espacio | Teletransporte corto (esquivar) |
| E | Interactuar, hablar, continuar |
| 4 · 5 | Beber una poción |
| K o Esc | El libro: inventario, diario, habilidades, estado |

El juego guarda solo. Las partidas están en `%APPDATA%\MagicianDemo`; para quitar
la demo, borra la carpeta que descomprimiste y esa.
